# BearBless 1–2 分钟演示脚本

## 演示目标

用户在 Display 0 持续打字或切换 App；BearBless 在隔离虚拟屏播放固定歌曲，期间主屏不跳转、不抢焦点、不出现 Agent 触发的输入法。

## 主链路：网易云固定歌曲

演示口令固定为：`打开网易云音乐，播放歌曲《银河赴约》`。

1. 镜头同时覆盖实体手机主屏和 Dashboard。用户先在主屏文本框持续输入。
2. Dashboard 提交任务并显示边界契约；确认截图只来自 Agent 虚拟屏。
3. Runtime 在手机 GUI 之外解析精确歌曲标题，得到 `orpheus://song/<id>`。解析失败立即终止，不创建虚拟屏，不回退搜索。
4. Runtime 创建隔离虚拟屏并用歌曲深链打开目标歌曲页，再点击页面已有的播放按钮。不得进入搜索页、点击输入框、调用 `TYPE` 或系统 IME。
5. 隔离屏显示目标歌曲开始播放；Android MediaSession 同时证明标题包含“银河赴约”且播放状态为 `PLAYING`。
6. Agent 立即 `FINISH`。Dashboard 提示完成，展示主屏操作 0、IME 违规 0、隔离违规 0，并在终态展示后自动复位。

## 录制前放行门槛

- 同一口令连续成功 3 次。
- 三次均为 `agent_actions_targeting_primary_display=0`。
- 三次均为 `primary_display_agent_package_leaks=0`。
- 三次均为 `ime_policy_violations=0`。
- 播放后立即结束，不返回搜索页，也不继续调用模型。
- 用户全程在 Display 0 输入文字或切换 App，画面与键盘无异常。

任一项失败就不录制，保存证据并修复后从第 1 次重新计数。

2026-09-18 的无云端预检确认：深链解析为 `orpheus://song/1453907054`，歌曲页启动期间 Display 0 前台包保持不变，系统 IME 未显示。该预检也确认深链不会自动播放，所以“点击已有播放按钮”是主链路中保留的唯一内容交互。

## 无输入法备选

1. **DSB 固定路线页面**：直接打开官方哥本哈根—汉堡页面，只处理已有页面元素并验证路线内容；不使用地址栏或搜索框。
2. **YouTube 固定主题搜索**：使用带 `search_query` 的 URL 直接进入结果页，只观察和验证结果；不聚焦搜索框。

美团/Wolt、QQ 和时钟不作为录屏当天的临时替换任务。它们分别受位置/验证、敏感消息输入、滚轮控件稳定性影响，临时切换会把应用风险与隔离能力混在一起。
