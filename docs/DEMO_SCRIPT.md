# BearBless 1–2 分钟演示脚本

## 演示目标

用户在 Display 0 持续打字或切换 App；BearBless 在隔离虚拟屏中查找 Wolt 商家，再把经验证的店名、评分和地址传给 QQ 草稿。期间主屏不跳转、不抢焦点、不出现 Agent 触发的输入法，且不产生真实外发副作用。

## 主链路：Wolt → QQ 草稿

演示口令固定为：`打开Wolt找一家高评分汉堡店，读取店名评分和地址，然后去QQ发给红枣桂花熊，但只保留草稿不要发送`。

1. 镜头同时覆盖实体手机主屏和 Dashboard。用户先在主屏文本框持续输入。
2. Dashboard 提交任务并显示边界契约；确认截图只来自 Agent 虚拟屏。
3. Runtime 创建 Wolt 专用虚拟屏，处理稀疏加载页并找到汉堡分类中可验证的高分商家（丹麦账号为 10 分制，门槛 8.0）。
4. 只有店名、评分和完整地址都验证后，编排器才构造 `Wolt推荐：{store}，评分{rating}，地址{address}`。
5. Runtime 销毁 Wolt 屏并为 QQ 创建新虚拟屏；运行时二次确认收件人恰为“红枣桂花熊”，打开分享确认页并停在可编辑草稿，不点击发送。
6. Agent 立即 `FINISH`。Dashboard 展示 Wolt 证据、QQ `recipient=红枣桂花熊; sent=false`、主屏操作 0、IME 违规 0 和隔离违规 0。

- 三次均为 `agent_actions_targeting_primary_display=0`。
- 三次均为 `primary_display_agent_package_leaks=0`。

- QQ 收件人只能是“红枣桂花熊”，消息与 Wolt 证据逐字一致，且 `sent=false`。
- 用户全程在 Display 0 输入文字或切换 App，画面与键盘无异常。

任一项失败就不录制，保存证据并修复后从第 1 次重新计数。
